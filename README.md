# alpasec — Терминал авторизации в контуре безопасности

Страница входа с фоном ортогональных линий телеметрии, динамическим переключением тем (Dark / Light) и пасхалкой Terminator 2 (Skynet).

---

## 📁 Структура проекта (Production)

В папке оставлены исключительно рабочие файлы финальной версии:

```text
D:\alpasec\
├── index.html                 # Главная и единственная веб-страница терминала
├── alpaca-dark.png            # Маскот темной темы (темные очки, прозрачный фон)
├── alpaca-light.png           # Маскот светлой темы (прозрачные очки, прозрачный фон)
├── alpaca-terminator.png      # Маскот киборга Т-800 для пасхалки (прозрачный фон, красный глаз)
├── alpaca-beige.png           # Резервный логотип (fallback)
│
├── nginx.conf                 # Конфигурация Nginx (Gzip, Cache-Control, Security Headers)
├── Dockerfile                 # Легковесный production-образ (nginx:alpine)
├── docker-compose.yml         # Скрипт быстрого запуска контейнера (порт 8080)
└── README.md                  # Документация проекта
```

## 🚀 Варианты деплоя и запуска

### 1. Локальный запуск
Дважды кликните по файлу `index.html` или откройте его в браузере.

### 2. Запуск в Docker
```bash
docker compose up -d --build
```
Страница будет доступна по адресу: `http://localhost:8080`

### 3. Деплой на веб-сервер (Nginx / Apache / Caddy / S3)
Скопируйте все 5 файлов (`index.html` и 4 PNG-изображения) в корень веб-директории вашего сервера.

## 💀 Пасхалка «Терминатор 2: Судный день» (Skynet Protocol)

1. **10 раз подряд** нажмите на иконку ламы (переключатель темы). Значок маскота начнет пульсировать красным светом (`primed-glow`).
2. Сразу после этого **13 раз подряд** нажмите на кнопку **«ПОКАЗАТЬ»** в поле ввода пароля.
3. На 13-й клик экран содрогается от глитча, звучит мотив Терминатора (5 металлических ударов наковальни Брэда Фиделя + брасс-гул), карточка переходит в режим `DEFCON 1`, маскот заменяется на киборга Т-800, а линии становятся лазерно-красными.

*(Один клик по кибер-ламе возвращает стандартную тему).*
